# Nail Master Dallas — Frontend Redesign Mockup

A one-page Next.js concept for Nail Master Dallas. It keeps the existing brand identity, product catalog, imagery, prices, and Shopify destination links while testing a cleaner navigation and merchandising system.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm start
```

The repository is ready for import into Vercel as a standard Next.js project.

## Notes

- Product and brand imagery comes from the current Nail Master Dallas Shopify storefront.
- Product, collection, account, cart, and policy links intentionally point to the live Shopify store.
- This is a frontend approval mockup only. It does not modify Shopify admin, themes, products, collections, inventory, or checkout.
